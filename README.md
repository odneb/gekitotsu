# GEKITOTSU 激突

A deterministic 2.5D arcade fighting game that runs in the browser.

Play: https://odneb.github.io/gekitotsu/

- `index.html` is the whole game in one file.
- `src/` holds the source it is built from. Run `python3 build.py` inside `src/`, then wrap the output as `index.html`.

## Credits

Fighter body mesh: "X Bot" from Adobe Mixamo (royalty-free character), repacked in `src/model.js`. All animation is hand-keyed in `src/render.js`; no Capcom assets are used.
