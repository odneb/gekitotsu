GEKITOTSU / PHYSICAL PRINT SET

The front end is rebuilt around a dedicated red, warm paper and ink-black physical set, 15,000 units above the existing arena. It uses the actual animated Robot 1 mesh, opaque extruded title geometry, Text3D headings and physical graphic planes. No runtime title PNG is loaded or drawn. Gameplay simulation remains in the arena below; menu models and planes are hidden and combat camera/postprocessing restored when a match begins.

The Latin title is custom polygon lettering with heavy stems, chamfered corners, angular counters and incisions, extruded four units. Japanese brush contours are a separate extruded mesh at their own depth. The opening holds a close punch composition, changes pose/framing every seven idle seconds, and uses independent lettering arrivals. The print surface has hard front/side shading; a subtle menu-only print finish unifies robot, geometry and text.

Main menu has four destinations: Versus, Training, Options and Quit. Options contains CPU level, Watch a Match, Button Settings, Move List, Sound & Effects and Back. Character selection displays the real hero plus eight live 3D costume previews. Player 2 is the same Robot 1 in an alternative costume. Stage selection frames the actual Dreadmarsh arena with a moving camera, six fixed weather palettes and a dynamic weather reel. Versus, pause, debug, results, controls and settings use the same identity. Start opens ordinary pause; Tab opens the debug menu.

Large headings, main choices, costume name, stage name, versus, victory, round/FIGHT/KO and combo counts use Text3D. The custom Gekitotsu Machina display font is a renamed OFL derivative of Anton; functional labels use Barlow Condensed SemiBold. Original font licenses and source URLs are included. Canvas labels, sliders, distress and transition strokes remain native runtime UI, not flattened artwork. Transitions use diagonal red/black cuts, confirmation streaks and existing menu sounds; character confirmation plays the existing Male 6 voice.

Authoring:
- tools/build_title_geometry.py creates both OBJ meshes.
- tools/import_title_geometry.py imports the meshes in Unreal.
- tools/build_display_font.py creates the custom display font.
- tools/make_print_set.py creates the two native print materials.
- tools/scripts/print_acceptance.txt exercises actual input routes, all costumes/weather, pause/debug, results/rematch, calls and garbage collection. It changes bindings and music volume: back up and restore Saved/gk_buttons.txt and Saved/presentation.txt around the run.
- tools/scripts/print_capture.txt records real HUD-on native frames.
- tools/scripts/print_realtime.txt exercises full audio and CPU matches on the real clock.

Launch tools/preview_forest.sh with no -gkfight argument to start at the title. Press Enter/Start, then choose Versus or Training. Arrow keys navigate, Enter confirms, Escape backs out. Gameplay keys are the user's saved bindings; Button Settings can remap all eight actions.

Scope: one character, eight costumes, one stage. This front-end rebuild does not add online modes, extra stages or a retail packaging pipeline. Purchased character, stage, voice and FluidNinja assets must be installed locally; they are not republished with source changes.
