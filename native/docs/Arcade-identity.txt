GEKITOTSU — native arcade identity

The approved direction combines the Industrial Impact title with the Jazz Riot colour
and motion language: vermilion, ink, cream and mustard, with hard cuts and large crops.
The original transparent wordmark is title artwork. Menus remain native controls over
live Unreal characters and the actual Dreadmarsh level. No full-screen menu mockup replaces
the scene.

Coverage
- Title and main menu: original logo, graphic monochrome grading, full-body/close/stage
  camera cuts every seven idle seconds. Input resets the idle sequence without changing
  the selected option. The live stage continues rendering under the native graphics.
- Character select: one Robot 1 presented large; only the active player's model is shown.
  Eight two-tone costumes, a new entrance when switching players, a 3D costume name,
  swatch pulses, lock-in stamps and layered confirmation sounds.
- Stage select: live level camera, extruded stage name, a weather preview reel when
  Dynamic Weather is selected. Explicit weather choices stay fixed. The reel changes
  every six seconds; choosing Dynamic still starts gameplay-driven weather.
- Settings, controls, help, pause, debug, versus and results share the new layout, type,
  selection treatment, footer and page transitions. Start/Escape remains normal pause;
  Tab remains quick debug. The animation lab is a separate developer tool.
- Combat HUD uses the same heavy type, cream/ink framing and vermilion P1 accents.
  Round/FIGHT/KO and other major calls, plus combo counts, use real extruded Text3D meshes.
  Native supporting labels stay sharp and readable. No combat timing or damage changed.

3D type
Epic's installed Text3D runtime plugin is enabled. Three reusable components cover the
headline and two combo counters. Geometry changes only when the word/count changes;
position, tilt and scale animate without regenerating the letters each frame. The owned
M_GkInkType material uses three hard value bands, cream faces and red bevel/extrusion.
The meshes do not cast interface-shaped shadows into the fighting stage. The title logo
itself is a transparent artwork asset, not an extruded custom-lettering mesh.

Build and tests
Build GekitotsuNativeEditor Mac Development with UE 5.8.4.
Copy tools/scripts/identity_acceptance.txt to Saved/script.txt and launch with -gkscript
-UseFixedTimeStep -FPS=60 for navigation assertions, actual KO/rematch, settings/help,
weather-reel and combat captures, plus forced garbage collection.
identity_capture.txt records real native transition frames. identity_realtime.txt checks
menu audio and normal-clock CPU combat. Offline captured videos are not performance tests.

Open normally using tools/preview_forest.sh or the supplied Launch Robot 1.command.
A game process already open keeps its old build. Quit and relaunch when ready; no live
coding reload or forced restart is performed during a player's session.

Limits
This is a tested native Development build. Shipping packaging and other hardware remain
unvalidated. Engine font files and the enabled Text3D plugin must be included when packaging.
The menu artwork and effects do not establish exact parity with the illustrative concepts.
